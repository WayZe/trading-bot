# Robustness-проверка donchian_trend: расширение на ADA/DOGE/LINK/XRP (2023–2026)

Дата: 2026-09-05. Продолжение исследования
`docs/research/2026-09-05-donchian-wf.md`: `donchian_trend` прошёл
риск-скорректированный критерий C2 на 2 из 3 исходных символов (BTC, ETH).
Этот документ — расширенная проверка робастности кандидата на **четырёх
новых символах** по протоколу, зафиксированному **до** прогонов. Нового кода
стратегий нет — только данные, прогоны и этот док.

## Протокол (зафиксирован ДО прогонов)

- **Данные**: Bybit spot, 4h, с 2023-01-01 — ADA/USDT, DOGE/USDT, LINK/USDT,
  XRP/USDT (ожидается ~8058 закрытых свечей на символ, как у BTC/ETH/SOL из
  прошлого исследования; если история монеты короче — фиксируем факт и гоним
  на том, что есть, окна нарежутся сами). Проверка валидации `validate_ohlcv`
  и дыр `find_gaps`.
- **Сетка** (`donchian`): entry_period ∈ {10, 20, 40, 55} × exit_period ∈
  {5, 10, 20} × atr_mult ∈ {1.5, 2.0, 2.5} = **36 комбинаций** (9 невалидных
  с `exit_period >= entry_period` отсеиваются валидацией стратегии —
  фактически 27, см. оговорку в прошлом доке); `atr_period` фиксирован = 14.
- **Фильтрованная сетка** (`donchian_trend`): та же + trend_period ∈
  {100, 200} = **72 комбинации** (фактически 54 валидных).
- **WFO**: rolling, is_days=180, oos_days=60, objective=sharpe — идентично
  прошлому исследованию; издержки — дефолтные из конфига (fee 0.1% за
  сторону, slippage 5 bps, позиция 95% equity). Конфиги:
  `config/research_donchian.yaml`, `config/research_donchian_trend.yaml`.
- **Прогоны**: 4 символа × {donchian, donchian_trend} = **8 walk-forward
  прогонов** (артефакты `reports/wf_<SYM>_donchian[_trend]/`; базовый
  `donchian` — для полноты сравнения). B&H за OOS-спан каждого прогона:
  доходность/Sharpe/maxDD через `benchmark_equity` +
  `compute_benchmark_metrics`.
- **Критерии** (сформулированы заранее, до просмотра результатов):
  - **C2-new (ключевой)**: `donchian_trend` проходит C2 (сшитый Sharpe >
    B&H Sharpe **и** сшитая |maxDD| < |maxDD B&H|) на **≥2 из 4** новых
    символов → робастность подтверждена; ровно 2 из 4 — «проходит, но
    хрупко»; **≤1 из 4** — кандидат не подтверждён.
  - **C2-total**: после расширения кандидат должен проходить C2 на **≥4 из
    7** символов суммарно (BTC/ETH/SOL + 4 новых) для статуса «подтверждён
    для testnet».
  - **C1 (сырой)**: сшитая доходность > B&H **и** |maxDD| < |maxDD B&H|.
    Считаем и репортим, но решения по нему не принимаем (в прошлом
    исследовании C1 не прошёл ни у кого из-за бычьего рынка).
- **Запрещено** менять сетки/окна/критерии после просмотра результатов;
  числа в отчёт идут как есть — отрицательный результат валиден.

Уточнение семантики критерия (как в прошлом исследовании): «просадка
меньше» = меньше *глубина* просадки, `|dd стратегии| < |dd B&H|` (значения
просадок в таблицах отрицательные).

## Результаты

Отклонений от протокола нет: все четыре датасета полные — по **8058
закрытых свечей** (2023-01-01 .. 2026-09-04 20:00 UTC), `validate_ohlcv`
без замечаний, `find_gaps` = 0, диапазон идентичен BTC/ETH/SOL из прошлого
исследования (сравнимость 1-в-1). Планировщик нарезал по **5 окон** на
прогон, тот же OOS-спан 2023-06-30 .. 2026-04-15, что и раньше. Окон
с ошибками: **0** во всех 8 прогонах (сетка как раньше фактически 27/54
валидных комбинаций).

## Вердикты по зафиксированным критериям

- **C2-new (ключевой): 3 из 4** — `donchian_trend` прошёл C2 на ADA
  (0.90 > 0.37), DOGE (1.26 > 0.60) и XRP (2.54 > 0.86) при меньшей
  просадке везде; не прошёл только на LINK (0.53 < 0.60 — отрыв в 0.07).
  По правилу «≥2 из 4 → подтверждена, ровно 2 → хрупко, ≤1 → не
  подтверждена» — **робастность подтверждена** (не на грани: 3 из 4).
- **C2-total: 5 из 7** — суммарно с исходными символами (BTC, ETH — да;
  SOL — нет) кандидат проходит C2 на 5 символах из 7. Порог
  «≥4 из 7 для статуса "подтверждён для testnet"» **выполнен**.
- **C1 (сырой), репортим без решений**: на новых символах C1 проходит
  чаще, чем в прошлом исследовании, — 3 из 4 для `donchian_trend` (ADA,
  DOGE, XRP) и 3 из 4 для base (LINK единственный минус по доходности).
  Причина та же, что делала C1 непроходимым раньше, только с обратным
  знаком: не бычий, а вялый альтсезон на OOS-спане новых символов (ADA
  B&H −15.5%, DOGE/XRP B&H сильно слабее стратегии). Решения по C1,
  как и зафиксировано, не принимаем.

Базовый `donchian` на новых символах тоже силён (C2 на 3 из 4, включая
LINK за счёт Sharpe 0.81 > 0.60) — расширение подтверждает работоспособность
обеих сеток, а не только композита.

## Оговорки

- Окон по-прежнему мало (5 на прогон), OOS-спан ~10 месяцев календарных
  на 3 года истории; аннуализированный Шарп сшитой кривой упрощён
  (календарные разрывы между OOS-отрезками) — как и раньше.
- Итог XRP держится на одном окне (ралли ноября-2024, +278%); итог DOGE
  — на двух (февраль-2024 и октябрь-2024). Один режим рынка (в целом
  благоприятный для трендовых выбросов в 2024-м) — выводы про «среднюю»
  доходность делать не стоит; критерий C2 это частично учитывает, но
  тоже не застрахован от режима.
- Проигрыш LINK по C2 близкий (Sharpe 0.53 против 0.60); SOL — единственный
  глубокий провал (−0.04 против 1.05). Выборка символов не случайная
  (крупные ликвидные альткоины Bybit spot), полная идентификация окон.
- B&H — наивная модель без комиссий и проскальзывания; стратегия платит
  обе стороны сделок: сравнение смещено в пользу B&H.
- Вывод справедлив для этой сетки (в валидной её части) и этого протокола;
  предрегистрация задним числом не менялась, числа — как есть.

## Итог

Robustness-проверка `donchian_trend` на 4 новых символах подтвердила
кандидата по обеим зафиксированным метрикам:

- **C2-new = 3/4** (ADA, DOGE, XRP; LINK — единственный проигрыш, и тот
  близкий) — не «проходит, но хрупко», а уверенное подтверждение;
- **C2-total = 5/7** (порог для testnet — 4 из 7) — выполнен.

Рекомендация для роадмапа: по предрегистрированным критериям
`donchian_trend` достигает статуса «подтверждён для testnet». Разумный
следующий шаг — зафиксировать рабочую параметризацию из устойчивого ядра
(entry ≈ 40, exit ≈ 10, atr_mult ≈ 1.5–2, trend_period ≈ 100–200,
переоптимизация раз в 60 дней как в WFO), добавить контроль риска на
уровне портфеля и выносить конфигурацию на testnet-прогон; параллельно
можно продолжать добор символов/режимов (особенно проверка на «плохом»
режиме типа SOL — сильный бычий тренд, который стратегия полностью
проигрывает) до выставления реальных ордеров. Основания для пересмотра
кандидата отсутствуют.
